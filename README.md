# Build-Upstream-Solutions-Landing-Page
Landing page website for Build Upstream Solutions, live at https://buildupstreamsolutions.com.

Hostinger deploys the `main` branch to `public_html` automatically on every push.

- `index.html`: the page (styles and script inline)
- `contact.php`: emails contact form inquiries to Rob and keeps a backup log outside `public_html`
- `images/`: logos, headshot and the Selected work images
